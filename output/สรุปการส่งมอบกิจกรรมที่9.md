# สรุปการส่งมอบ Mockup กิจกรรมที่ 9 ระบบหมายจับ

วันที่ทดสอบ: 16 สิงหาคม 2569

## ไฟล์หลัก

- `index.html` — Mockup แบบ Single-page ที่เปิดใช้งานและเปลี่ยนสถานะได้
- `pdf/คู่มือการใช้งานระบบหมายจับ_กิจกรรมที่9.pdf` — คู่มือ 29 หน้า
- `video/วิดีโอสาธิตระบบหมายจับ_กิจกรรมที่9.mp4` — วิดีโอคำอธิบายภาษาไทย 110 วินาที ขนาด 1920×1080

## ขอบเขตโฟลวที่ทำแล้ว

1. รับข้อมูลสำนวนจากกิจกรรมที่ 5 และเปิดงานกิจกรรมที่ 9
2. ทะเบียนคำร้อง ค้นหา กรอง และนำเข้าหมายเก่า
3. จัดทำคำร้อง ปปท.8-17 หรืออัปโหลด Word/PDF
4. ส่งเจ้าของสำนวน ผู้บังคับบัญชา และ ผอ.สำนัก/กองตรวจ
5. สร้างชุดยื่นศาล แยกเอกสารภายในกับเอกสารยื่นจริง
6. ยื่นศาลแบบ Manual และสำรองช่องทาง AWIS ที่ยังปิดระหว่าง MOU
7. บันทึกผลศาล: ออกหมาย ขอแก้ไข นัดไต่สวน โอนศาล ไม่อนุมัติ และถอนคำร้อง
8. ตรวจและยืนยันหมายที่ศาลออก พร้อมอัปโหลดเอกสาร
9. ธุรการคดี กอท. ตรวจรับ ลงทะเบียนคุม จัดหนังสือนำส่ง และส่งตำรวจ
10. ส่งทางไปรษณีย์หรือนำส่งด้วยตนเอง พร้อม Tracking/หลักฐาน
11. ติดตามหมายและเลือกแผนจับกุม 4 รูปแบบ
12. บันทึกผลจับกุม ไม่พบตัว หลบหนี ต่อสู้ มอบตัว อายัดตัว ตาย ขาดอายุความ หรือคำสั่งศาล
13. ส่งมอบผู้ต้องหาให้อัยการและเก็บหลักฐาน
14. ตรวจเหตุยุติ จัดชุดเสนอ และผู้มีอำนาจอนุมัติ/ขอข้อมูลเพิ่ม/ไม่อนุมัติ
15. แจ้งยุติให้ตำรวจและสำนัก/กอง โดยไม่มี Police API
16. สำนัก/กองรายงานศาล ขอถอนหมาย บันทึกผลศาล และยื่นเอกสารเพิ่มโดยเก็บเลขรับเดิม
17. บันทึกถอนหมายเมื่อศาลมีคำสั่ง แจ้งหน่วยงานและปิดงาน
18. ตรวจครบ 180 วันและแจ้ง ผอ.ทะเบียนกลาง กรมการปกครอง
19. Dashboard กราฟ ตัวกรอง และ Export Word/Excel/PDF
20. Notification ผ่าน Email/LINE/Push และ Audit Trail ในระดับ Mockup

## ข้อจำกัดของ Mockup

- ข้อมูลตัวอย่างอยู่ในหน่วยความจำและเริ่มใหม่เมื่อ Reload หน้า
- ยังไม่มี Backend, Database, Authentication/Authorization และ Digital Signature จริง
- ยังไม่เรียก Tracking API, Email, LINE หรือ Push จริง
- AWIS ยังปิดไว้จนกว่า MOU และ API Contract จะพร้อม
- ไม่มี API เชื่อมระบบตำรวจตามข้อมูลที่ยืนยัน

## ประเด็นที่ต้องยืนยันก่อน Production

1. สายอนุมัติจริงของเอกสารแต่ละประเภท
2. หลักเกณฑ์เลือกแบบคำร้องทั้ง 3 แบบและ Template สุดท้าย
3. ชุดข้อมูล/เอกสารที่กิจกรรมที่ 5 ส่งเข้ากิจกรรมที่ 9
4. รูปแบบเลขทะเบียน เลขหนังสือ และผู้มีอำนาจลงนาม
5. AWIS MOU และ API Contract
6. Tracking API และรหัสสถานะจริง
7. ถ้ามี API กรมการปกครอง ต้องยืนยัน Payload และความหมายผลตอบกลับ
8. แบบรายงาน กราฟ ตัวกรอง และ Export ที่ลูกค้าต้องการจริง
9. สิทธิ์เข้าถึงพยานหลักฐานและข้อมูลส่วนบุคคลของแต่ละบทบาท
